# MindShift web MVP

Sunumdaki öğrenci odaklı akışın tarayıcı prototipi.

Çalıştırma: `python3 -m http.server 4173 --directory dist`

Ardından http://localhost:4173 adresini açın. Bağımlılık kurulumu veya derleme gerekmez.

Günlük ruh hali ve motivasyon kaydı, kurallara göre 15/25/40 dakikalık çalışma önerisi, hedef tamamlama, kalıcı odak sayacı, düşünce günlüğü, gölet temizliği ve balık ekleme, geçmiş ve JSON dışa aktarım içerir.

Veriler aynı tarayıcıdaki localStorage içinde saklanır. Hesap, sunucu veritabanı, cihazlar arası senkronizasyon, gerçek AI/NLP veya klinik değerlendirme bulunmaz. Psikolojik etkililik iddiası yapılmaz.
